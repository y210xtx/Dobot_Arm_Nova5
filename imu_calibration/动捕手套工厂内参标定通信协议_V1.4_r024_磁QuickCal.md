# 动捕手套工厂内参标定通信协议 V1.4 r024 磁 QuickCal

本版本在 r024 原始流协议基础上恢复 M01～M04，并将掌部磁传感器质量加入最终报告。

## 能力确认

上位机在开始前发送 `GET_VERSION (0x08)`。type=8 固定 48 字节，其中：

- revision：`24`
- tag：`r024-fac-magq`
- features bit4 (`0x10`)：M01～M04 为必做阶段，type=7 包含磁质量
- features bit5 (`0x20`)：staged MCAL
- features bit6 (`0x40`)：加速度内参
- features bit7 (`0x80`)：type=9/type=11 工厂原始流

四项能力和版本必须全部匹配，否则上位机禁止发送 `MCAL_BEGIN`。

## 正式阶段

阶段严格按下列顺序执行：

`P1 → A01…A06 → G01…G06 → M01 → M02 → M03 → M04 → MCAL_COMMIT`

磁阶段命令仍为 `MCAL_STAGE (0x13)`：

| 阶段 | arg | captureMask | 动作 | 采集时间 |
|---|---:|---:|---|---:|
| M01 | `0x30` | `0x08` | 像 G03/G04 一样固定进入阶段时的 TCP XYZ，将初始 Tool 参考系 Ry 俯仰 ±75° 与 J6 方向 Tool Rz 旋转 ±75° 合成为同一个姿态目标，使用 MovL 连续插补并监视实际 J6 偏移，最后回到进入 TCP 位姿 | 40 s |
| M02 | `0x31` | `0x08` | Tool Rx Yaw `0°→+45°→0°` 单侧往返 | 10 s |
| M03 | `0x32` | `0x08` | Tool Rx Yaw `0°→-45°→0°` 单侧往返 | 10 s |
| M04 | `0x33` | `0x08` | 标定中位静止安全收尾 | 0 s（先静止 5 s） |

M01～M03 期间固件以约 15 Hz 采集磁场；MMC5983MA 三轴 span 均不得低于 400 counts。
M04 仍按协议开启并关闭 `0x33` 阶段以保留完整阶段审计，但固件明确禁止在 M04 调用
`TriMag_CalFeed()`，因此静止收尾不会污染磁场 min/max 和质量报告。

## type=7 v4 最终报告

总长度为 1110 字节。前 1046 字节保持 type=7 v3 的 Gyro/Accel 布局，末尾追加 64 字节磁质量：

| 偏移（相对 1046） | 长度 | 含义 |
|---:|---:|---|
| 0 | 1 | `magOk` |
| 1 | 1 | `rejectFlags` |
| 2 | 1 | `seenMask`，bit0 为 MMC5983MA |
| 3 | 1 | slot 数，固定 3 |
| 4 | 60 | 3 个 slot，每个 20 字节 |

每个 slot：`samples(u16), spanX/Y/Z(u16), offsetX/Y/Z(i16), scaleX/Y/Z×1000(u16)`。

`rejectFlags`：

- bit0：MMC5983MA 未采到数据
- bit1：MMC5983MA X 轴覆盖不足
- bit2：MMC5983MA Y 轴覆盖不足
- bit3：MMC5983MA Z 轴覆盖不足

报告 flags bit2 表示磁质量段存在。最终通过条件为 Gyro 11/11、Accel 11/11、Mag 通过且 Flash 写入成功；任何一项失败，本次参数不写入 Flash。
